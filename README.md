Funcionalidades do Projeto:

 - Busca de produtos através da API.
 - Listagem de produtos encontrados.
 - Adição de produtos ao carrinho.
 - Consulta dos itens presentes no carrinho.
 - Comunicação entre interface gráfica e API REST.

Tecnologias Utilizadas:
  - Python
  - FastAPI
  - SQLAlchemy
  - API Rest
  - requests
  - Git e GitHub
  - Uvicorn

Estrutura do Projeto:
  - Aplicacao/
  - Models/
  - Routers/
  - Schemas/
  - readme.md

Como Executar
1. Clonar o repositório
git clone https://github.com/Sander-Roni/MyCarrinho.git
cd MyCarrinho
2. Criar ambiente virtual
python -m venv venv
3. Ativar ambiente virtual

Windows:

venv\Scripts\activate

Linux/Mac:

source venv/bin/activate
4. Instalar dependências
pip install -r requirements.txt
5. Executar a API
uvicorn main:app --reload
6. Executar a aplicação gráfica
python NomeDaAplicacao.py
